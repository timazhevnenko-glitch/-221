# Банк Железного Банкира

Консольный кредитный калькулятор на C++. Считает переплату и ежегодный платеж по займу. Использует простые проценты.

## Описание

Программа спрашивает сумму займа, ставку и срок в годах. Потом выводит переплату, общую сумму к возврату и ежегодный платеж. Код короткий и понятный.

## Сборка

```
g++ main.cpp -o calculator
```

Запуск на Windows:

```
calculator.exe
```

Запуск на Linux или macOS:

```
./calculator
```

## Возможности

- Ввод суммы займа, ставки и срока
- Расчет переплаты
- Расчет общей суммы к возврату
- Расчет ежегодного платежа
- Вывод результата на русском языке

## Пример работы

```
=== Банк Железного Банкира ===
Введите сумму займа: 1000
Введите процентную ставку (в %): 10
Введите срок в годах: 3

=== Результат ===
Сумма займа: 1000 золотых
Переплата: 300 золотых
Общая сумма к возврату: 1300 золотых
Ежегодный платеж: 433.333 золотых
```

## Формулы

- Переплата = сумма * ставка * срок / 100
- Общая сумма = сумма + переплата
- Ежегодный платеж = общая сумма / срок
